
# Precursors Extreme Events

This repository contains the code used in the project **Extreme Event Precursors**, which focuses on identifying, learning, and evaluating **data-driven precursors of extreme events** in high-dimensional chaotic dynamical systems.

The framework combines concepts from dynamical systems, reduced-order modeling, and modern machine learning to construct predictive indicators for rare and extreme events, with applications to fluid flows and related complex physical systems.


---

## Overview

The goal of this project is to learn a mapping from precursor quantities to future **energy dissipation**, enabling the anticipation of extreme events at different prediction horizons.

Two types of input representations are supported:
- **FTLE-based features** (default)
- **Fourier-based features** (provided for comparison)


---

## Data

The `data/` directory contains the time-series datasets used in this study.

- `X_FTLE.npy`  
  Time series of FTLE-based features, including the leading FTLE and its time derivative.

- `X_Fourier.npy`  
  Time series of the real and imaginary parts of the Fourier mode (1,0).

- `y_dissipation.npy`  
  Time series of the corresponding energy dissipation of the Kolmogorov flow.

All datasets are aligned in time and are used to construct input–output sequences for training, prediction, and evaluation.

---

## Code Structure

The `dissipation-prediction/` directory contains the code used in this study.


### Main training and prediction script

The main entry point of the project is `main.py`.  
This script performs **training and prediction** using a **Transformer-based architecture**.

- **Input**: FTLE or Fourier-based features  
- **Output**: Future energy dissipation  


All results generated by `main.py` are stored in the `outputs/` directory. Results are organized by prediction lead time:

Specifically, each `tau_*` subfolder contains:
- Trained model checkpoints
- Prediction outputs
- Evaluation metrics
- Plots comparing ground truth and predictions


---

### Configuration and utilities

- `args.py`  
  Defines all command-line arguments controlling data selection, model configuration, training, and prediction. More explanation below.

- `src/`  
  Contains the core implementation, including data loading and preprocessing, model definitions, training and prediction routines, loss functions, metrics, and plotting utilities.



---

### Reproducing manuscript figures

The script `plots_manuscript.py` reproduces the **figures presented in the manuscript**.  
It loads saved predictions and ground-truth data from completed experiments and generates comparison plots and performance metrics.

All figures generated by this script are saved in: outputs/plots_for_manuscript/

## Command-line interface

All experiments are configured via command-line arguments defined in `args.py`.

The most important arguments are:

- `--inp`  
  Input representation:
  - `FTLE` (default): FTLE-based precursors  
  - `Fourier`: Fourier-mode–based features (for comparison)

- `--tau`  
  Prediction lead time (τ)

- `--lookback`  
  Length of the input history window

- `--label`  
  Length of the prediction window

- `--model_architecture`  
  Model type (default: `Transformer-based`)

- `--train_model`  
  Train the model

- `--predict_model`  
  Run prediction and validation after training

All other parameters (architecture, optimization, and training defaults) are specified in `args.py`.

### Example

```bash
python main.py \
  --inp FTLE \
  --tau 15 \
  --lookback 60 \
  --label 30 \
  --train_model \
  --predict_model
```
